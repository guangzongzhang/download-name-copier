# 下载资源名称复制助手

> Edge / Chrome 浏览器插件 —— 识别网页上的可下载资源，右键一键复制文件名称或直接下载并自动命名。

## 功能特性

### 右键菜单功能

| 右键位置 | 菜单选项 | 说明 |
|---------|---------|------|
| 下载链接 | **复制文件名称** | 提取识别到的文件名称（优先取页面显示的中文名）复制到剪贴板 |
| 下载链接 | **复制链接文字** | 复制链接的可见锚文本 |
| 下载链接 | **下载并自动命名** | 调用浏览器下载，文件名自动填为识别到的中文名，无需手动改名 |
| 页面空白处 | **复制本页所有下载文件名称** | 扫描整页下载链接，逐行复制全部文件名 |
| 页面空白处 | **复制本页所有下载文件名称（含链接）** | 以 `文件名<TAB>URL` 格式复制 |
| 选中文本 | **复制所选文字** | 直接复制选中文本 |

### 工具栏弹窗

点击浏览器工具栏的插件图标，弹窗中列出当前页面检测到的所有下载资源，可逐个复制或全部复制。

### 智能文件名识别

很多网站（尤其政府/文档站点）的下载链接 URL 是系统生成的哈希文件名（如 `6ae443884d2a4ff684f7793591e15c50.docx`），但页面上显示的是中文名称。本插件采用三级识别策略：

1. **链接文字带文件扩展名** → 直接使用（如 `湖南省...通知.docx`）
2. **链接文字是有效名称**（非"下载""点击下载"等通用短语） → 使用链接文字（如 `《湖南省房屋安全鉴定管理办法（征求意见稿）》`）
3. **链接文字为空或通用短语** → 回退到 URL 提取文件名

## 安装方法

1. 打开 Edge，地址栏输入 `edge://extensions/`。
2. 打开右上角 **「开发人员模式」** 开关。
3. 点击 **「加载解压缩的扩展」**。
4. 选择 `download-name-copier` 文件夹。

## 使用方法

- 在含下载链接的页面上，**右键点击下载链接** → 选择「复制文件名称」。
- 在页面空白处**右键** → 选择「复制本页所有下载文件名称」。
- 点击工具栏插件图标，弹窗中可查看并逐个复制。

## 常见问题

### Q: 为什么复制的是哈希名而不是中文名？
A: 请确保已刷新扩展和网页。最新版本已优先使用链接的可见文字作为文件名。

### Q: "下载并自动命名"弹出的文件名还是哈希名？
A: 极少数网站的链接文字就是哈希名。此时可先用"复制链接文字"确认页面显示的名称，再手动修改。

### Q: 右键菜单没有出现插件选项？
A: 请确认已在 `edge://extensions/` 加载本扩展，并已打开"开发人员模式"。
